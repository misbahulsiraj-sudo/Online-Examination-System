# 📔 Online Examination System

A Python-based Online Examination System that allows students to register, log in, take multiple-choice exams, and view their results through a simple console interface.

## Features

- Student registration and login
- Password hashing
- Multiple-choice questions
- Randomized question order
- Exam timer
- Automatic answer evaluation
- Score and percentage calculation
- Automatic grade generation
- Pass/Fail status
- Result history
- Results saved in JSON format
- Clean menu-driven interface

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling
- Random Module
- Time Module
- SHA-256 Hashing

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python online_exam.py
